Men Haqimda
Men Frontend yo‘nalishida o‘qiyotgan dasturchiman. HTML, CSS va JavaScript texnologiyalarida ishlay olaman. Oddiydan murakkabgacha bo‘lgan veb-saytlarni yaratish, responsiv dizayn tuzish va interaktiv sahifalar yaratishga e’tibor qarataman. Hozirda JavaScript bilimlarimni chuqurlashtirib, React.js va zamonaviy frontend texnologiyalarini o‘rganmoqdaman.

HTML5, CSS3, JavaScript: Bu uchala vep dasturchilik ko'nikmalaridan bilimlarim yetarlicha
Responsive Web Design: bundan ham bilaman ammo hozirda shuni bilish bilan ovoraman
DOM Manipulation: Bu narsani bilaman ammmo chuqur tarzda emas yuzaki uslubda
Basic Git and GitHub: Bular dan men alochiman buni git hup sahifamdan bilishin giz mumkin
